# Kick-off-now

Kick-off-now 是一个面向多种生活场景的“启动仪式”产品，帮助人们为工作、阅读、运动等不同活动建立专属仪式，减少启动阻力，更快进入当下需要的状态。

产品关注的不是单一场景的任务管理，也不是单纯打卡，而是通过“场景—目标状态—启动仪式—立即行动”的稳定联系，训练用户的状态切换能力。用户还可以选择在活动后进行轻量复盘，逐步微调并找到更适合自己的启动仪式。

> 为不同场景建立专属启动仪式，训练自己更快进入想要的状态。

当前项目仍处于产品发现阶段，暂不预设具体功能形态。现阶段将优先验证产品定位、用户需求、真实使用场景与核心痛点。详见 [产品发现文档](docs/product-discovery.md)。
